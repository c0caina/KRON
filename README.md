# KRON minimal

Минимальный harness для телефона с root: модель, один инструмент `console`, поле сообщения и ответ. Модель сама решает, какие команды выполнять, как работать с файлами и устанавливать программы. Нет хаба, узлов, proot, менеджера моделей, отдельных файловых инструментов, планировщика или собственной системы прав.

## Запуск

```sh
cargo build --release
./target/release/kron
```

Первый запуск создаёт `kron.json` в текущей папке. Заполните `base_url` (OpenAI-совместимый Chat Completions API), `model`, `api_key`, затем перезапустите. Для локального API ключ может быть пустым. Можно использовать внешний прокси подписок, но встроенных OAuth-адаптеров нет.

Откройте `http://127.0.0.1:7790`. Экран содержит только сообщение, отправку и последний ответ. Контекст диалога хранится в памяти до перезапуска. Агент вызывает `console` сколько нужно до финального ответа; инструменты и мысли не рисуются. После ошибки запрос можно повторить; уже выполненные команды при этом не откатываются.

`KRON_CONFIG` задаёт путь к JSON; `KRON_LISTEN` — локальный IP и порт. Сервер принимает только loopback. Запросы страницы проверяются по Origin; это не ограничение прав агента. Подтверждений команд и песочницы нет.

## Android с root

APK запускает бинарник в foreground service. При старте `su -c 'id -u'` запрашивает root у Magisk / KernelSU; разрешите постоянный доступ. Каждый вызов `console` выполняется через `su -c` непосредственно на Android. На Linux используется `sh -c` с правами процесса.

После первого запуска отредактируйте `/data/data/io.github.k0de1ne.kron/files/kron.json` через root-терминал или файловый менеджер, затем принудительно остановите и откройте приложение. Это единственная настройка подключения; отдельного экрана настроек нет.

Команды работают в новых shell: используйте явные пути или `cd`. Ввод stdin не поддерживается; длительные задачи запускайте фоном с выводом в файл. Возвращаются код выхода и stdout/stderr (до 32 КиБ каждого потока). Таймера и ограничения количества шагов нет. Root даёт права, предоставленные вашим root-менеджером; SELinux и ограничения Android сам harness не меняет.

## Сборка APK

Нужны Rust target `aarch64-linux-android`, NDK, JDK, Android SDK 35 / build-tools 35.0.0:

```sh
cargo build --release --target aarch64-linux-android
android/build.sh target/aarch64-linux-android/release/kron kron.apk
```

В CI собираются Linux-бинарник и Android APK без Ubuntu и llama.cpp. Сборки веток доступны как Actions artifacts; релиз `latest` обновляет только `main`.
